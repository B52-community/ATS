      Reference Architecture

      Data Ingestion

      • Exchange WebSockets + failover providers.
      • Raw stream normalization per symbol.
      • Kafka/NATS for event fanout + replay.
      • Heartbeat and feed drift monitoring.

      Low-Latency Compute

      • Rust/Go services for order-book and flow math.
      • Feature store for per-symbol rolling metrics.
      • Python model service for confidence calibration.
      • Hard risk gateway before alert generation.

      Signal Delivery

      • WebSocket API for live UI updates.
      • Push alerts: in-app, Telegram, Discord, email.
      • Per-user threshold and instrument filters.
      • Audit log for every signal + rationale.

      Implementation Plan

      1. Phase 1: Core feed adapters, feature extraction, baseline signal scoring (BUY/SELL/WAIT).
      2. Phase 2: Heatmap + cluster detection, confidence model, live alert routing.
      3. Phase 3: Backtest harness, walk-forward validation, regime-based weighting.
      4. Phase 4: Multi-asset scaling, portfolio-level risk controls, user customization.
